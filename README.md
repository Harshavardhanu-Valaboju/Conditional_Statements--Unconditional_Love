# ❤️ Code To Impress

A fun Python project created using basic programming concepts.

## 📖 Story Behind This Project

While sitting in a boring class, I got a random thought:

"What if I use Python to impress my girl?" 😄

Instead of just learning concepts theoretically, I decided to apply what I learned and build something fun and interactive.

This project demonstrates how simple programming concepts can be transformed into creative ideas.

## 🚀 Concepts Used

- User Input (`input()`)
- Conditional Statements (`if-else`)
- Loops (`while`)
- String Methods (`lower()`)

## 💻 How It Works

1. User enters `open`.
2. The program displays a surprise message.
3. It asks a fun question.
4. The loop continues until the user enters `yes`.
5. A sweet message is displayed.
